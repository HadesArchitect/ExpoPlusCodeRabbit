# Project

## Overview

This project is a demo project to show use of CodeRabbit AI review platform with Expo framework and Linear issue tracker.

### App Description

StickerSmash is a simple Expo/React Native app that lets users pick a photo, add emoji stickers on top of it, and save or share the result. It's based on the official Expo tutorial and serves as a realistic playground for demonstrating AI-powered code review workflows.
